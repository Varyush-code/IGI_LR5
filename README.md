# Информационная система зоопарка

Данный проект реализует веб-сайт для зоопарка. С помощью сайта посетители могут знакомиться с животными, читать новости, оставлять отзывы, просматривать информацию о билетах и вакансиях. Сотрудники могут работать с информацией о кормлении животных, помещениях и статистике.

Основная цель проекта — объединить информацию о зоопарке в одном месте и упростить работу с ней. Посетителям не нужно искать информацию на разных ресурсах, а сотрудникам удобнее получать данные о животных и обслуживании зоопарка.

В системе предусмотрено несколько ролей пользователей: "посетитель" может просматривать информацию о животных, читать новости, оставлять отзывы и работать с разделом билетов; "сотрудник" имеет доступ к дополнительным разделам, связанным с кормлением животных, помещениями и статистикой; "Администратор" управляет системой и её данными. В проекте также предусмотрена административная панель Django.

Для реализации сайта используется язык программирования Python. Для разработки веб-приложения используется Django, который отвечает за обработку запросов, маршрутизацию, работу с данными и отображение страниц. В качестве системы управления базами данных используется PostgreSQL 15. Для запуска приложения и базы данных применяется Docker Compose.

Проект построен по принципу клиент-серверного веб-приложения.
Пользователь открывает сайт в браузере и отправляет HTTP-запрос. Django принимает запрос, определяет нужный маршрут и передаёт его соответствующему приложению. Приложение выполняет необходимую логику, при необходимости обращается к PostgreSQL и формирует HTML-страницу. После этого ответ возвращается пользователю.

В проекте используются отдельные Django-приложения, каждое из которых отвечает за свою область.

`apps.core` — главная страница и общая информация о зоопарке.
`apps.animals` — информация о животных, их названиях и семействах.
`apps.news` — новости зоопарка и связанные с ними изображения.
`apps.accounts` — регистрация пользователей, профили и роли.
`apps.employees` — контакты сотрудников.
`apps.feeding` — информация о кормлении животных и количестве использованного корма.
`apps.reviews` — отзывы посетителей.
`apps.tickets` — раздел, связанный с билетами.
`apps.openings` — информация о вакансиях.
`apps.enclosures` — информация о помещениях и местах содержания животных.
`apps.statistic` — статистические данные о посетителях, животных, кормлении и билетах.

Главная точка интеграции с данными — PostgreSQL. В Docker Compose для базы данных заданы имя `zoo`, пользователь `zoo\_user` и пароль `zoo\_pass`. Данные базы хранятся в Docker volume `postgres\_data`. Медиафайлы Django могут храниться в файловой системе контейнера или в подключённом каталоге. Для них в проекте предусмотрены `MEDIA\_URL` и `MEDIA\_ROOT`. В режиме отладки медиафайлы раздаются через механизм Django. Для работы приложения используется файл `.env`, из которого Docker Compose получает переменные окружения.

# Инструкция для запуска

Для запуска необходимы Docker и Docker Compose, а также исходный код проекта. Сначала нужно перейти в корневую папку проекта и проверить наличие файла `Dockerfile` и файла `.env`. В `.env` должны быть заданы необходимые настройки Django и подключения к базе данных.

Запуск контейнеров выполняется командой: *docker compose up --build -d*
После запуска контейнера необходимо настроить окружение: *.\\venv\\Scripts\\Activate.ps1*
И запустить проект: *python manage.py runserver*
После успешного запуска сайт должен быть доступен по адресу: *http://localhost:8000/*
Административная панель Django находится по адресу: *http://localhost:8000/admin/*

Перед запуском необходимо проверить, что настройки Django, подключение к PostgreSQL и переменные окружения соответствуют текущему окружению. Если база данных ещё не готова к подключению в момент запуска Django, может потребоваться настройка ожидания готовности PostgreSQL.
